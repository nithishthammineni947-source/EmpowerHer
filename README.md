# EmpowerHER

AI-powered women's safety web app: abuse classification (TF-IDF + SVM), severity detection, legal guidance and SOS alerts.

## Live demo
https://nithishthammineni947-source.github.io/EmpowerHer/

## Features
- Text and voice incident reporting
- Category and severity prediction
- Legal sections and helplines (India)
- SOS alert with live location to trusted contacts
- Dashboard of analysed reports

## How to run
Open the live demo link in Chrome or Edge. No installation needed.
